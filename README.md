# ⚡ Quick Text Formatter & Cleaner

An optimized, exceptionally lightweight, single-page client-side web application built to format, parse, validate, and clean textual data in real-time. Built entirely with pure semantic HTML5, modern layout CSS variables, and native JavaScript utility engines.

🔗 **Live Deployment:** [https://github.io](https://github.io)

---

## 🚀 Core Features

- **Real-Time Workspace Analytics:** Live, high-performance execution listeners that monitor character weight and accurate word separation boundaries automatically.
- **Lexical Format Controls:** Instantly transform text arrays into unified configurations, featuring structural global `UPPERCASE` maps and `lowercase` string modifications.
- **Whitespace Sanitizer Engine:** An isolated custom regular expression system (`/\s+/g`) designed to reduce excessive tab spaces, erratic paragraph breaks, and carriage line returns down into a balanced, clean space arrangement.
- **Native System Clipboard Integrations:** Single-click async memory channel processing to select, cache, and securely transfer formatted results straight into target platform mobile/desktop clipboards.
- **Privacy-First Workspace:** ZERO server logs or background APIs. All operations parse natively within the local browser sandbox for total information containment.

## ⚙️ Quick Installation & Setup

Because this ecosystem runs purely within a client browser runtime, there are zero packages, compilers, Node modules, or development servers to initialize.

### Run on Local Engine
1. Clone the project pipeline directory:
   ```bash
   git clone https://github.com
   ```
2. Navigate directly to your local file bundle:
   ```bash
   cd text-formatter
   ```
3. Open `index.html` inside any modern browser choice (Chrome, Safari, Firefox, Edge).

## 🌐 Automatic Deployment via GitHub Pages

This application can go live instantly using GitHub's distributed native edge hosting frameworks:

1. Push your consolidated script components to your main repository branch.
2. Jump over into your online **GitHub Repository Panel Settings**.
3. Locate the **Pages** directory section hidden under the sidebar navigation menu.
4. Select your core deploy pipeline structure (**Deploy from a branch**) and toggle the source target node to `main` (or `/root`).
5. Save the state changes. GitHub Actions will handle building and publishing your system live in under 60 seconds.
